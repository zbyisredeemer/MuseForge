# Contributing to MuseForge

Thank you for contributing.

## Contribution Areas

### Prompt Dataset

Add structured prompt data:

- country
- culture
- clothing
- environment
- pose
- lighting
- photography

### Code

Preferred stack:

- Backend: Python / Java / Node.js
- Frontend: React / Vue
- Database: PostgreSQL / SQLite

### Data Format

All prompt data should be:

- structured
- reusable
- documented
- culturally respectful

## Pull Request Guidelines

1. Create a meaningful branch
2. Explain your changes
3. Add examples when adding prompt templates
4. Keep commits focused
