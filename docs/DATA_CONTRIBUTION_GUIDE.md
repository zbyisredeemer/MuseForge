# Dataset Contribution Guide

## Goal

Build a high quality AI beauty prompt knowledge base.

## Contribution Types

- New beauty styles
- New clothing styles
- New locations
- New photography presets
- New prompt examples

## JSON Rules

- Keep naming consistent
- Add meaningful tags
- Avoid duplicate entries
- Include English keywords for AI models

## Review Process

1. Submit Pull Request
2. Validate schema
3. Review quality
4. Merge
