# MuseForge Architecture

## Core Concept

MuseForge uses a modular prompt knowledge graph.

```
User Intent
    |
Prompt Generator
    |
Knowledge Modules
    |
Final AI Prompt
```

## Modules

- Identity
- Culture
- Appearance
- Clothing
- Scene
- Pose
- Emotion
- Camera
- Lighting
- Style

## Future

- Search engine
- Recommendation system
