# Prompt Quality Scoring

MuseForge evaluates prompts from multiple dimensions.

## Dimensions

### Beauty Completeness

Checks whether the prompt contains:

- beauty style
- appearance
- clothing
- makeup

### Scene Quality

Checks:

- location
- season
- atmosphere

### Photography Quality

Checks:

- lens
- lighting
- composition

### Model Compatibility

Checks whether output fits:

- Midjourney
- Stable Diffusion
- Flux
