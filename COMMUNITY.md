# MuseForge Community Contribution Guide

## How to contribute

MuseForge welcomes contributions of:

- New beauty styles
- Cultural fashion data
- Prompt examples
- Photography parameters
- UI improvements
- Generator algorithms

## Dataset contribution rules

Each contribution should include:

- Clear category
- Structured JSON format
- English keywords
- Example prompt
- Appropriate attribution when needed

## Pull Request checklist

- [ ] Data format validated
- [ ] No duplicated entries
- [ ] Description included
- [ ] Example prompt provided

Together we build a global AI beauty aesthetics database.
