# Changelog

All notable changes to MuseForge are documented here.

## [Unreleased]

### Added

- 100-concept Beauty Gallery with five top-level category groups
- Search, random discovery, and deterministic similar-style recommendation
- Interactive React Gallery and Prompt Studio
- Generic, Midjourney, FLUX, and Stable Diffusion prompt adapters
- Prompt adapter API endpoints and adapter unit tests
- Docker development workflow and GitHub Actions validation
- Draft 2020-12 JSON Schemas and reusable dataset validation script
- Structured beauty attribute dataset
- Prompt generation API design

### Changed

- Prompt Studio now keeps a canonical MuseForge prompt and renders model-specific outputs.
- Gallery metadata is shared consistently by dataset, Web, and API builds.

## [0.1.0] - Initial Release

### Added

- Global beauty style knowledge base
- Clothing, scene, camera, makeup datasets
- Prompt engineering documentation
- Community contribution guidelines
